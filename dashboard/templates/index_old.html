04 /Data & methodology

What this version of the interface currently displays.

Transparent by design. Both charts and all figures come from your existing results_file1.json and results_file2.json via the original Flask loader. If a file is missing or unreadable, the existing backend supplies zero-valued fallbacks. A zero alone therefore cannot confirm that an export is present. The time-series, claim verdicts, community scores, leaderboard and verification bot in the visual references need their own real data/backend integration; this redesign does not fabricate them. This dashboard is analysis, not investment advice.
